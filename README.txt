ТОО itEDM — современный сайт на HTML, CSS и JavaScript

Как открыть:
1. Распакуйте архив.
2. Откройте файл index.html в современном браузере.

Структура:
- index.html — разметка и тексты сайта
- style.css — адаптивный дизайн и анимации
- script.js — слайдер, интерактивная ДНК-сеть, молния и форма WhatsApp
- assets/ — логотипы и изображения

Основные функции:
- адаптивная главная страница;
- три слайда с автоматическим переключением;
- интерактивная ДНК-паутина, притягивающаяся к курсору;
- визуальный эффект грозы и молнии;
- карточки услуг с подъёмом, наклоном и подсветкой при наведении;
- форма заявки, формирующая сообщение для WhatsApp.

Контакты и тексты можно менять непосредственно в index.html.
